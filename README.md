# Бот-розыгрыш «Колесо призов»

Что делает бот:
1. Знакомится с гостем: имя → телефон (кнопкой) → дата рождения.
2. Просит вступить в вашу Telegram-группу и проверяет, что гость действительно вступил.
3. По кнопке «Крутить колесо» отправляет гифку колеса, которая останавливается на выпавшем призе, и пишет приз текстом.
4. Один гость — одна прокрутка. Все данные сохраняются в базу.

Админ-команды (только для ADMIN_IDS): `/export` — таблица гостей (CSV, открывается в Excel), `/stats` — статистика.

## Запуск
1. Создайте бота у @BotFather → получите токен.
2. Добавьте бота в вашу группу **администратором** (иначе он не сможет проверять вступление).
3. Узнайте id группы (перешлите сообщение из группы боту @getidsbot или @username_to_id_bot) — он вида `-100...`.
4. Скопируйте `.env.example` в `.env`, заполните.
5. `pip install -r requirements.txt`
6. `python make_gifs.py` (если меняли призы)
7. `python bot.py`

Чтобы бот работал круглосуточно, запустите его на любом хостинге/VPS (Railway, Render, Timeweb и т.п.).

## Настройка
Тексты и призы — в `config.py`. Шанс приза задаётся числом `weight`.
Своя гифка: положите файл `gifs/spin_0.gif`, `spin_1.gif`… (номер = порядок приза в списке).
