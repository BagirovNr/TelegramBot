# Бот-розыгрыш THE CHOCO

**Гость:** имя → телефон (кнопкой) → вступает в группу → «Вы участвуете».
**Админ (вы), в день розыгрыша:** команда `/draw Название приза` → подтверждение → бот случайно выбирает победителя среди тех, кто сейчас состоит в группе, отправляет в группу гифку колеса и объявление, пишет победителю в личку, а вам присылает его телефон и Telegram.
Приз можно не указывать — тогда будет написано «подарок от THE CHOCO»: `/draw`.

Команды админа (id из ADMIN_IDS): `/draw [приз]`, `/stats` (сколько участников), `/export` (таблица CSV для Excel).
Один человек не может выиграть дважды: при повторном `/draw` прошлые победители исключаются.

## Запуск
1. Бот создан в @BotFather, добавлен в группу **администратором**.
2. Переменные (на хостинге или в `.env`): BOT_TOKEN, GROUP_ID=@the_choco_spb, GROUP_LINK=https://t.me/the_choco_spb, ADMIN_IDS.
3. `pip install -r requirements.txt` → `python bot.py`

## Бесплатный Render
Web Service (Free). Build: `pip install -r requirements.txt`, Start: `python bot.py`.
Бесплатный сервис засыпает через 15 минут — настройте пинг адреса раз в 5 минут (uptimerobot.com).
Файловая система на бесплатном Render сбрасывается при перезапуске → база может обнулиться. Делайте `/export` каждый день и обязательно перед розыгрышем.

## Настройка
Все тексты — в `config.py`. Своя гифка колеса — положите файл в `gifs/draw.gif`.
Картинки для BotFather (`/setdescriptionpic`, `/setuserpic`) лежат в `assets/`.
